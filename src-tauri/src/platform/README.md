# 平台接口目录

本目录承接 Host 的操作系统接口。当前 macOS 实现保留在已有 Rust 文件中；Windows 实机成果接入时，在同一个提交中完成接口提取、调用方修改及平台验证。

| 接口范围                 | 当前涉及文件                            | 平台实现位置         |
| ------------------------ | --------------------------------------- | -------------------- |
| 程序启动、环境、进程回收 | `agent/native.rs`、`agent/providers.rs` | `macos/`、`windows/` |
| 渠道和工作区锁           | `locks.rs`                              | `macos/`、`windows/` |
| 本机 IPC                 | `mcp_bridge.rs`                         | `macos/`、`windows/` |
| 路径、原子替换、目录同步 | 文件工具与持久化调用方                  | `macos/`、`windows/` |

接口提取时由 `mod.rs` 声明公共类型并通过 `cfg(target_os)` 选择真实实现。权限、审批、revision、模块规则与数据库访问仍由公共 Host 管理。操作失败直接返回明确错误，保留错误位置和必要路径信息。

目录中的说明文件记录接入规则；实际 Rust 模块随着平台实现一起提交并接受编译验证。
